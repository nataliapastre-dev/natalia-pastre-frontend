## 🛠️ Tecnologias Utilizadas no Portfólio

O portfólio foi desenvolvido utilizando uma stack moderna para aplicações Front-End:

* ⚛️ **React:** Construção da interface através de componentes reutilizáveis e organização modular do projeto.
* 📘 **TypeScript:** Tipagem estática para maior segurança do código e facilidade de manutenção.
* ⚡ **Vite:** Ferramenta de build rápida e alta performance no ambiente de desenvolvimento.
* 🎨 **Tailwind CSS:** Interface moderna, responsividade e componentes visuais estilizados.
* 🎬 **Framer Motion:** Animações, transições e interações visuais dinâmicas.
* 🧭 **React Router:** Gerenciamento da navegação e rotas da aplicação.
* 🐙 **Git & GitHub:** Versionamento e publicação do projeto.
